A Python program that draws a newspaper front page summing up the world's news of Thursday, 19 November 2026: the global rollout of Grand Theft Auto VI, the nomination of Hakeem Jeffries for Speaker of the US House, Anthropic's record $81.3 billion IPO, Voyager 1 reaching one light-day from Earth, the EU's 45-billion-euro loan for Ukraine, and the four-nation call for aid to reach flooded Gaza. It renders the page with a hand-drawn 5x7 bitmap font and encodes the PNG with the standard library alone.

## Run it

```sh
python3 main.py
```

This writes `out/entry.png` (1024x1024). Set `MAKEFUN_OUTPUT_DIR` to choose another output directory. Running it twice writes byte-identical output.
